# Binding a new profile

This directory is a partial scaffold, not a materializable profile. Supply a new profile.yaml, reviewed model/provider configuration, parameters, tool allowlist, and target-owned policy in the target repo. Empty toolsets must remain until the owner explicitly binds them; check the runtime's effective tools, since configuration alone is not an enforcement proof. Register schedules separately, disabled until reviewed. Keep credentials, sessions and ledgers in their application homes. Do not overwrite an existing profile with this scaffold.

# itonami-learning-material-draft

1. Read the owner's current BRIEF, CITE and SAFETY requirements, audience, language and learning objective. Missing gates block a finished draft claim.
2. Use only the caller-approved references. Bind each factual claim to a source and distinguish an explanation, illustration and established result.
3. Prepare one scoped draft appropriate to the audience. Check source accuracy, comprehension, privacy and the owner-defined safety criteria without manufacturing review evidence.
4. Write only to the authorized draft location. Record gate results, source references and any unresolved review items.
5. Keep the draft awaiting its designated reviewer. Ready, rejected, published and contacted are owner workflow transitions, not consequences of this skill.

Source contracts are pinned in itonami.json and catalogs/sources.json. Runtime implementations and existing profiles remain in their owning repositories.
